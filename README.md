# Governance Wiki

智能体系统治理的中英双语学习网站，英文为默认页面。本次交付是本地开发版本，尚未部署。网站使用原生 HTML、CSS 和 JavaScript，无运行时第三方依赖；内容已预生成，支持 GitHub Pages 静态托管和 `#/` 路由。

## 设计与内容

参考 [DeepSeek Harness 学习站](https://dsh.papertok.ai/#s0-1) 将正文、目录、笔记、练习与进度放在同一学习工作区的方式，减少阅读时的切换。参考 [Audit Commons Learn](https://auditcommons.org/learn/) 从概念到评估报告、再到工作表的引导路径，以及对外部行动证据和结论边界的强调。

本站以 survey 当前 Chapter 3 的五项治理职责组织学习入口：**任务约定对齐（Mandate Alignment）、执行监督（Execution Oversight）、故障处置（Fault Resolution）、多智能体协调（Multi-Agent Coordination）、可审计性保障（Auditability Assurance）**。每篇保留一个贯穿案例，三个小节对应该职责的三项要点。五项职责可以共享检查与证据，不要求按固定阶段运行；治理决定权限决定在有效授权内由 governance agent 自主处理，还是由人介入作出决定。

2026 年 10 月 26 日更新：保留采购、订金支付与销售报告更正情境；文档处理与报销仍各用一个案例，分别突出致因修正与既有产物修复、审批范围与职责的证据追溯。相关难点以语义、授权和证据判断说明，同时明确固定工程机制可以承担的部分。

当前包含：

- 11 篇完整文章、学习路径、文章目录与全文搜索。
- 阅读标记、文章笔记、笔记导出、可填写并导出的治理分析工作表。
- 授权演示：正常投递、排队后撤权、排队后更改获准收件人；支持逐步执行、运行全部与重置。
- 浅色／深色模式和移动端布局。

笔记、工作表和阅读进度保存在当前浏览器的 `localStorage` 中，不进行跨设备同步。更换浏览器、站点地址或清除网站数据后不会保留原有记录；需要长期保存时请导出。

## 本地预览

在本仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 [知识库首页](http://127.0.0.1:4173/#/) 或 [交互实验室](http://127.0.0.1:4173/#/lab)。运行预览不需要安装内容构建依赖。

## 语言切换

参考 [Audit Commons](https://auditcommons.org/) 的 `EN / 中文` 入口。未指定语言的地址默认英文；`?lang=zh` 指定中文，`?lang=en` 明确指定英文，例如 `/?lang=zh#/article/mandate`。切换保留当前文章和小节，不根据浏览器系统语言覆盖选择。站内路由保留语言参数，复制链接可以分享当前语言。

搜索使用当前语言的完整正文，原文下载返回对应语言。笔记、已读记录和工作表按同一文章 ID 共享，切换语言不改写用户输入。英文不是摘要版；五项职责仍各使用一个案例，结构与中文对应。

## 维护内容

中文正文维护在仓库同级的 `../wiki/`，英文全文维护在 `../wiki/en/`。英文文章标题、导语等元数据位于 `../wiki/en/metadata.json`；中文元数据位于生成脚本。两种语言使用相同的文章 ID 与小节顺序。生成脚本将 Markdown 分别复制到 `content/` 和 `content/en/`，转换链接、生成对应锚点，并输出双语 `assets/content.js`。修改任一语言后重新生成：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python scripts/sync-content.py
```

构建依赖仅为 `Markdown==3.7`。也可指定其他原文目录：

```sh
.venv/bin/python scripts/sync-content.py --source-dir /path/to/wiki
```

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面框架、导航与搜索弹窗 |
| `assets/styles.css` | 主题与响应式布局 |
| `assets/i18n.js` | 从地址读取语言，提供显式双语文案选择 |
| `assets/app.js` | 双语界面、路由、搜索、阅读状态、笔记和工作表 |
| `assets/content.js` | 自动生成的文章、目录与自测数据 |
| `assets/lab.js` | 独立的浏览器教学演示 |
| `content/` | 自动复制的 Markdown 下载原文 |
| `scripts/sync-content.py` | 内容构建与链接转换 |

`content/` 和 `assets/content.js` 会被重新生成覆盖。正文应修改相应语言的维护源；修改结构时请同步另一语言的小节顺序，构建会校验锚点对应关系。
